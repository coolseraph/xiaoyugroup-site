# XiaoYu Group staging site

This folder is the static GitHub Pages deployment package for the staging domain. The homepage is `index.html`, focused engagements are in `engagements.html`, and the case library is in `cases/`. Shared case illustrations are stored once in `assets/illustrations/`.

All HTML pages carry a `noindex, nofollow` robots meta tag, and `robots.txt` asks crawlers not to index this staging site. These settings do not make the site private.

In the project workspace, regenerate this package with `node .project/build_github_release_it024.cjs`. The site owner approved the cases and logos for staging on 3 October 2026. The source ledger remains in the private project workspace.
